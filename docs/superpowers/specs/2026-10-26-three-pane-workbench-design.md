# 正式三栏工作台重构

用户已在对话中批准三栏原型及深色 XML，并明确要求开始正式重构；本文件记录已批准范围，不引入新的视觉方向。

- 左：真实历史与进行中的实验卡片，点击切换实验，不触发创建或运行。
- 中：同一实验的参数解析、XML 复核、真实结果图片、实验进度四个视图；切换视图保留右侧对话和待确认卡片。
- 右：模型对话、等待耗时/取消、内嵌参数修改交互卡片。修改卡片后接受必须先由后端重新校验候选参数，再接受返回的提案 ID，不能把本地改动伪装成原提案授权。
- 两条可拖拽分隔线支持鼠标/触摸和键盘，合理最小宽度、记忆比例、恢复默认；窄屏以三个区域切换呈现，不把正文挤出屏幕。
- XML 使用黑底等宽字体及安全的语法高亮，保持展示文本字节内容不变；新执行预览的实际程序路径、命令、输入、输出、过期和明确确认门禁完整保留。历史 XML 只读，不提供重执行按钮。
- 图片只读取实际注册的 PNG/JPEG 等产物，并标明实验、日期和 attempt；没有图片时显示空态，不混入演示结果。
- 保留 GLM 思考设置、取消和耗时功能。已冻结/已有任务的计划保持只读，失败重试仍经过独立预览与确认。
- 不启动真实 GREAT、不请求真实 GLM、不重做绘图、不合并/提交/推送、不迁移项目目录，保留其他脏工作区改动。
- 用户只批准前端重构，后台执行语义不改变；如需读取历史 XML，仅添加安全只读接口。

实现选择：沿用 React/TypeScript，无新依赖；复用已有运行监控和执行复核；新增布局、只读参数、提案卡片、产物浏览和 XML 着色小组件。页面对话暂存于浏览器内存，不将 prompt 写入 localStorage；实验切换时隔离会话并取消旧模型请求。
