# 引用英文换行与译文标签修复 — 2026-11-15

已更新正式前端；本轮不修改数据库、解析索引或后端服务。

## 原因与处理

- 原文引用使用 `white-space: pre-wrap`，把 PDF 的行尾固定带到窄侧栏；`overflow-wrap: anywhere` 也允许截断完整英文词。新增 `CitationExcerpt`，保留原始文本节点与空行段落，显示时将段内硬换行作为普通空白。原文和译文的阅读正文采用正常词边界；过长的单词只在片段内部横向滚动。中文可正常换行，代码、表格、KaTeX 保持各自规则。引用原文、API 摘录校验和复制内容未改写，也不猜测合并科学词汇的连字符。
- 译文/上下对照按钮原先在没有本地译文时直接禁用；更换目标语言又会清除本地译文，造成截图中的标签无法选择。现在点击标签即可请求所选语言并显示对应视图；已有结果直接切换。请求结束不强制跳回对照视图；加载时可切回原文，失败可点同一标签重试。原有取消、语言/来源切换、晚到结果拒绝及撤权保护保留。
