Use only when the user requests a plan change and the binding is writable. Tools: get_current_plan, propose_plan_change. Read the current plan, preserve unrelated values, create a complete candidate and a short explanation. A changed default_15 station list uses custom station_group_id. Validation failure means no claimed successful change. A no-change response has no proposal card.
